# Kanchi Kamakshi 3D Jewellery Works — Simplified Client Version

This version follows the client's simpler business-website plan.

## Home
- Brand name centered at the top: KANCHI KAMAKSHI / 3D JEWELLERY WORKS
- Tagline directly below
- One central interactive 3D jewellery object
- Left/right arrow controls only; no numbered indicator
- Five homepage jewellery models: Ring, Necklace, Bangle, Earrings, Bracelet
- Cursor movement subtly tilts the 3D object
- The selected object enters with a smooth horizontal 3D transition
- Simple customer CTAs

## Pages
- Home
- About Us
- Services
- Our Work / Gallery
- 3D Printing & Designs
- Jewellery Collection
- Contact Us

The pages are intentionally clean and business-focused. Complex technical/specification panels, oversized forms, extra navigation controls and heavy homepage sections were removed.

## Important
The current 3D models are lightweight procedural placeholders so the interaction can be tested without client GLB files. Replace them with the client's optimized GLB/GLTF models when supplied.

Client photos and founder photos can be added later without changing the page architecture.
